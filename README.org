# -*-org-*-

* Welcome to Emacs
  This is customized init file to remind myself of how to use Emacs
  and my personal customizations.

  - This file itself is in [[info:org][Org]] mode.  Use =C-c C-o= to visit any
    hyperlink in this doc.
  - To edit this file, press =C-x C-q= to disable read-only mode.

* Languages Supports

*** Common for Interpreters

    For interpreter languages, such as Python or Ruby, here are common
    key bindings:

#+BEGIN_SRC
    C-c !        Start the interpreter
    C-c C-b      Execute buffer
    C-c C-r      Execute region
#+END_SRC

    For additional bindings, look at the corresponding init files in
    [[file:init/]]

*** Python

    Historically I've used 3rd party mode, =python-mode.el= where the
    built-in =python.el= was not good enough.  Now =python.el= looks
    mature enough, and 3rd parties to support virtual environment
    seems to support =python.el= only, I switched to the vanilla
    =python.el=.

    I'm using [[https://github.com/pyenv/pyenv][pyenv]] with =pyenv-mode.el=.  Before launching Python
    shell (=C-c !=), select the right Python version using =C-c C-p=.

    For block indent, use =C-c <= or =C-c >= after marking the region.

***** Pandas

      For /pandas/, if you want to adjust the display width option
      matched with the actual width of the inferior Python shell
      window, use =C-c C-q=.

      Pressing =C-c C-f C-p= to parse the tabular data into DataFrame,
      and evaulate in the inferior Python buffer.

      =C-c C-f C-o= to parse the org table at the point, and evaluate
      it.

  that matches with the current buffer.  (e.g. GIT, SVN or CVS)

*** Terminal (Ghostel)

    screen(1)/tmux(1) like terminal interface is available. (via [[https://github.com/dakra/ghostel][ghostel]])

    =M-x ghostel= or =M-x ghostel-project= to create a terminal.
    
    Within the terminal, you can use:
#+BEGIN_SRC
  C-z "         list all terminal(ghostel) sessions
  C-z C-z       switch to the other terminal (most recently used)
  C-z a         send C-z to the terminal
  C-z n         switch to the next terminal
  C-z p         switch to the previous terminal
  C-z c         create new terminal
  C-z C         create new terminal for the current project
#+END_SRC

    Several shell functions are available for interacting Emacs.  See
    [[./ghostel.bash]] for more.
    
* Emacs features that I forgot frequently
*** Force inserting characters
    - =C-q <tab>= to insert a =<tab>= character.
    - =C-q C-j= t= insert a newline (useful when query-replace)

*** isearch

    - =C-w= pull next word or character into search string
    - =M-C-w= pull next symbol or character into search string
    - =M-C-d= delete a character from end of the search string
    - =M-s e= edit search string
    - =M-s c= toggle case fold
    - =M-s r= toggle regexp
    - =M-%= query-replace
    - =C-M-%= query-replace-regexp
      
*** Removing lines with a pattern

    Select a region (e.g. =C-x h= for whole buffer), then =C-u M-|=
    (=shell-command-on-region=) to execute =grep -v PATTERN=.

*** Keyboard Macros

*** Rectangle Mark Mode
    To select rectangular region, press =C-x SPC=.  Then you can do
    =C-w= or =M-w= as usual.

    When you do M-x replace-regexp, you could insert =\,(LISP...CODE)=.

*** Recursive Edit
    =C-r= to start it, =C-M-c= to exit, =C-]= to abort.
    See also [[info:Emacs#Recursive Edit]]

*** Completing read /w Helm
    Emacs has various ways to read the predefine input using completion.
    The additional package, [Helm](https://github.com/emacs-helm/helm) also
    override this interface to use it's own mechniasm.

    - To select none (to return =""=), Use =C-RET= or =M-RET=.

*** Dired

    - =0 w= copy the absolute file name into the kill ring.
    - =% d= flag files for deletion with the regular expression
    - =% m= mark files with the regular expression

    - =* c= change existing mark to another
    - =M <DEL>= remove specific mark
      
    =dired-omit-mode= is turned on, which means uninteresting files
    are not visible by default (e.g. backup files).  To make it
    visible, press =C-x M-o= (toggle dired-omit-mode).  To mark
    omitted files, press =* O=.

*** Org mode
    
***** Insert Word Joiner or Zero-Width Space
      To mark up word with Korean postposition, since it is attached
      with the words, Org mark up will not detect them.  Insert
      word-joiner character using =C-c C-;=.  If the text contains
      quotation, and Emacs couldn't detect the text correctly, use
      =​C-c C-'​= to insert zero-width space character.  Here's the
      example where you need to insert the special character (marked
      at =<!>=):
    
#+BEGIN_EXAMPLE
      =foo=<!>는              # word-joiner
      =<!>C-c C-'<!>=         # zero-width space
#+END_EXAMPLE

*** Calc

    =s t=  Assign top-most value to a variable and pop it.
    =s s=  Assign top-most value to a variable

***** Formula and Variables

#+BEGIN_EXAMPLE
'(F - 32) * 5 / 9
<RET>                        # duplicate the top-most item
100 <RET>
s t F                        # store 100 into a variable F
=                            # evaulate
<TAB>                        # exchange top two items
<RET>                        # duplicate
80 <RET>
s t F
=
<TAB>
#+END_EXAMPLE

#+BEGIN_EXAMPLE
'C * 9 / 5 + 32 = F
<RET>
'[0, 20, 35, 100]
s t C
=
v u                          # vector to values
#+END_EXAMPLE

***** Solving Proportions
      
      To solve "1345:1=x:350000" for =x=, just replace ':' with '/',
      and type in Algebraic mode (').  Then, press =a S= and type 'x'

#+BEGIN_EXAMPLE
1345/1=x/350000
a S x<RET>                   # solve the equation for 'x'
j 2<RET>                     # select 2nd part
<RET>                        # copy the selected part (number) into the stack
#+END_EXAMPLE

* Features I added/modified
*** remove all whitespaces
    zap-to-nonspace, [[file:init/delete.el::delete-chars-forward-with-syntax][delete-chars-forward-with-syntax]] can delete
    one or more whitespaces starting from the point(cursor).
    Use =C-c C-d=.

*** launch VCS(version control system) like git, CVS, SVN, etc.
    =<f12>= bounds to [[file:src/vc-dirx.el][vc/dir]], which is smart enough to launch
    corresponding Emacs feature for VCS it detects.  For git(1), it
    uses [[https://magit.vc/][magit]].

*** Compile    
    =C-c c= bounds to =dwim-c/compile=, which try to understand the
    build(compile) tool name from the context.

*** insert License clause
    To insert license clause on your text file, do =M-x insert-license=.

*** Capitalize Words
    =M-c=, or =M-x capitalize-word+= will capitalize (or
    de-capitalize) current word in the point.

    For example, if the point is somewhere around "hello", pressing one or
    more =M-c= will result "Hello", "HELLO", or "hello".

    It may use the other capitalized word if it found from other
    buffers.  For example, if there was a word "EmaCS" available in
    current (or anyother) buffer, it will use it as one of candidates.

*** Unfill paragraph
    Select the region, then pressing =M-Q= will change the paragraph
    to a single line.  This is useful to create for example, Github
    friendly markdown text.

*** Shell
    =M-x shell= will behave like a login shell.

*** Fonts
    - Use `M-x fontutil/set-font` to change the font family.
    - Use mouse scroll up/down to increase/decrease font size

    See [[file:src/fontutil.el][fontutil.el]] for more

      Turn off read-only this buffer (=C-x C-q=), evaluate the code block

      Update =fontutil/default-fontconfig= in [[file:src/fontutil.el][fontutil.el]].  Make sure you
      undo by =C-_=.  (Or =C-c C-v k=).

#+BEGIN_SRC emacs-lisp
(fontutil/remove-unavailable fontutil/default-fontconfig t)
#+END_SRC

*** man pages on MacOs (darwin)
      
    On Mac, =man(1)= does not support cached index which makes completion
    on man pages extremely slow (e.g. in /helm/ or /ivy-mode/).

    Installing =man-db= with Homebrew and updating the index via
    =mandb(1)= will improve the performance.  However, it has too many
    dependencies which makes me not comforable due to limited space on
    my Mac.
